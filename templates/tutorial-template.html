⚠️ Common Pitfalls

Watch out for these mistakes:

  1. Forgetting to validate input: Always check that your input data matches expected formats. Invalid data will cause silent failures.

    # ❌ Risky
result = process(data)

# ✅ Safe
if validate_data(data):
    result = process(data)
else:
    raise ValueError("Invalid input data")

  2. Not handling edge cases: Consider what happens with empty inputs, very large datasets, or unusual values.

  3. Skipping error handling: Always wrap external calls in try-except blocks to prevent cascading failures.

  4. Ignoring performance: Test with realistic dataset sizes early to identify bottlenecks.

🔴 Critical Warnings

These mistakes could cause data loss or security issues:

⚠️ Never hardcode credentials in your source code. Use environment variables or secret management systems:

# ❌ NEVER DO THIS
api_key = "sk_live_51234567890abcdef"

# ✅ DO THIS INSTEAD
import os
api_key = os.getenv('API_KEY')
if not api_key:
    raise ValueError("API_KEY not found in environment")

⚠️ Always backup data before running transformations:

# Create backup before processing
cp data/input/raw_data.csv data/input/raw_data.csv.backup

⚠️ Validate results after processing to ensure data integrity.

### ⚠️ Common Pitfalls

::: {.callout-warning appearance="minimal" icon="true"}
**Watch out for these mistakes:**

1.  **Forgetting to validate input:** Always check that your input data matches expected formats. Invalid data will cause silent failures.

    ``` python
    # ❌ Risky
    result = process(data)

    # ✅ Safe
    if validate_data(data):
        result = process(data)
    else:
        raise ValueError("Invalid input data")
    ```

2.  **Not handling edge cases:** Consider what happens with empty inputs, very large datasets, or unusual values.

3.  **Skipping error handling:** Always wrap external calls in try-except blocks to prevent cascading failures.

4.  **Ignoring performance:** Test with realistic dataset sizes early to identify bottlenecks.
:::

### 🔴 Critical Warnings

::: {.callout-danger appearance="minimal" icon="true"}
**These mistakes could cause data loss or security issues:**

⚠️ **Never hardcode credentials** in your source code. Use environment variables or secret management systems:

``` bash
# ❌ NEVER DO THIS
api_key = "sk_live_51234567890abcdef"

# ✅ DO THIS INSTEAD
import os
api_key = os.getenv('API_KEY')
if not api_key:
    raise ValueError("API_KEY not found in environment")
```

⚠️ **Always backup** data before running transformations:

``` bash
# Create backup before processing
cp data/input/raw_data.csv data/input/raw_data.csv.backup
```

⚠️ **Validate results** after processing to ensure data integrity.
